# 四象限待办——昔涟帮你记录待办事项

把"后面要做的事"告诉昔涟，她按**重要 × 紧急**四象限整理成彩色清单：重要紧急（红）、重要不紧急（绿）、不重要紧急（黄）、不重要不紧急（蓝）。随时间自动滑动优先级、自动提醒、自动结算完成状态；桌面独立窗口提供待办全景。

插件 id：`quadrant-todo`（工具前缀 `quadrant-todo_*`）。

## 功能一览

| 功能 | 说明 |
|---|---|
| 四象限待办 | 对话登记（时间/内容/分类）、自动滑动、主动提醒、完成状态、修改/删除/反悔 |
| 大目标拆解 | "我想学英语过四六级"这类长时限目标，辅助拆成有明确时限的小目标（随功能二上线） |
| 工作台 | 独立窗口三形态：四象限视图 / 日历视图 / 已完成列表 |
| 移动端提醒 | 可选：配置 NapCat 后，提醒同步推送到你的 QQ 私聊 |

## 安装与使用

1. 在 Cyrene 中 **设置 → 插件 → 导入 ZIP**（或从插件市场安装）
2. 在插件列表中**启用**本插件
3. 直接跟昔涟说话即可，无需任何配置
4. 手动到插件页面打开插件ui

## 用起来什么样

以下均摘自真实对话记录（2026-10-29 实测验收）：

> **你**：记一下语文作业的事。
> **昔涟**：记语文作业这事人家接下了♪ 明天是 10 月 29 日周四，得把时间落准一点，才不会提醒得太晚。
> **昔涟**：记好了：**语文作业 · 不重要紧急 · 截止 10 月 29 日（周四）20:00**，已经躺在你的待办列表里了，到点程序会提醒你。

分类不用你懂术语——她只问"要紧吗、着急吗"，听完你的态度再自己归格：

> **你**：帮我记一下，明天早上起来跑步。
> **昔涟**：人家本来按你说的，放进了「要紧但不那么急」那格，可程序看了看时间，明天早上九点离现在不到一天，就自己把它滑到「重要紧急」里去了。这个滑动是插件按时间自动做的，我争不过它呀。

删除也是一句话的事：

> **昔涟**：三门都删掉了——语文、历史、英语，一条不剩♪

## 提醒是怎么工作的

> 本节为目标行为（重构落地中），当前进度见文末"开发状态"。

- **零授权**：不需要去任何界面确认，登记完就生效。插件默认重要的事项是需要主动通知的，不重要的事项是不需要主动通知的
- **系统通知**：提醒以 Windows 系统通知弹出（进通知中心留痕），点击通知直接打开待办工作台
- **两种提醒**：重要不紧急滑入紧急象限时提醒一次；重要紧急剩 24 小时时提醒一次；不重要的全程静默
- **错过补发**：Cyrene 关机错过提醒时刻的，下次开机自动补发
- **一轮重置**：修改截止时间即开启新一轮，会重新提醒

## 边界与隐私

- 数据只存在本机插件私有目录，不上传、无遥测
- 插件不修改宿主任何代码，全部经公开插件 API 实现
- QQ 私聊可用全部功能；**群聊禁用**（宿主安全策略）
- 移动端提醒仅在配置 NapCat HTTP 后启用，外发的是登记时生成的预写文案，不经过宿主会话记录
- 插件运行依赖 Cyrene 在线；关机期间到点的提醒开机补发

## 常见问题

**为什么不用宿主的"定时任务"做提醒？**
s提醒是确定性的时间事件，不该需要用户逐条授权。本插件用系统通知直达，登记完即生效。

**手机 QQ 上能收到提醒吗？**
配置 NapCat HTTP 后可以（见设计文档 3.4）；未配置时提醒只在电脑端弹出。

**任务 72 小时内会自动变红，能不让它变吗？**
滑动是时间规则，代码说了算。想让事项退出紧急状态，修改它的截止时间。

**记错分类了怎么办？**
随时口述让昔涟改，或在待办工作台里手动编辑——你的修改永远以最新为准。
